# Security policy

During alpha, the latest minor release receives security fixes. Report malformed-log crashes, path traversal, unsafe deserialization, report injection, dependency vulnerabilities, or accidental sensitive-data publication through GitHub Private Vulnerability Reporting. Do not attach a sensitive ULog to a public issue.

Include the affected version, synthetic/minimized reproduction, impact, and mitigation if known. Maintainers aim to acknowledge reports within three working days and coordinate disclosure according to severity and available capacity.

PX4 Dataset Builder is an offline engineering data tool. Its output is not a flight-safety, airworthiness, anomaly ground-truth, or operational decision.
